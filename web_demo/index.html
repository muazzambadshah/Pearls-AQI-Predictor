How it works
  1. Data: hourly Open-Meteo weather, pollutants and US AQI for Lahore since 2023, the same source as my Hopsworks feature pipeline.
  2. Features: AQI lags (0–72h), 24h rolling stats, PM2.5/PM10/NO₂/CO, weather forecast at the target hour, calendar terms and the horizon itself. That makes one global direct model for every horizon from 1 to 72h.
  3. Models: HistGradientBoosting with an absolute-error median plus 10% and 90% quantile models. The interval is then calibrated with conformalized quantile regression per horizon bucket on a separate calibration window.
  4. Evaluation: chronological hold-out with a 72h gap, compared against persistence and 24h-seasonal-naive baselines.
  5. Deployment: the trees are exported to JSON (bit-exact with scikit-learn) and evaluated in JavaScript, so no server is needed.

The full production pipeline (Hopsworks feature store, a 4-model ensemble, FastAPI and GitHub Actions) is in the GitHub repo. This page is the lightweight browser version of that forecaster.
